# 수동 스모크 체크리스트

각 Phase 완료 시 실제 Netflix에서 아래를 확인한다. 자동 테스트(픽스처)는 레이아웃·번역기·DRM을 재현하지 못하므로 이 목록이 최종 게이트다.

## 준비
1. `npm run build` → `chrome://extensions` → "압축해제된 확장 프로그램 로드" → `dist/` 선택
2. 외국어 자막이 있는 아무 타이틀 재생 (예: 노르웨이어 자막)
3. 우클릭 → "한국어로 번역" (브라우저 번역기 활성화)

## 체크 항목

### A. 재생 시작
- [ ] 플레이바에 확장 버튼(자막 아이콘)이 나타난다
- [ ] 원본 자막 아래(스택 모드)에 번역 자막이 표시된다
- [ ] 원본 자막은 번역되지 않고 원문 그대로다
- [ ] 콘솔에 uncaught 에러가 없다

### B. 자막 흐름
- [ ] 자막이 바뀔 때 번역 자막도 따라 바뀐다
- [ ] 자막이 사라질 때 번역 자막도 사라진다 (잔상 없음)
- [ ] 두 줄 자막이 정상 표시된다
- [ ] 긴 자막이 화면 밖으로 나가지 않고 폰트가 줄어든다

### C. 비디오 전환
- [ ] 다음 에피소드 자동재생 후에도 번역 자막이 계속 표시된다
- [ ] 뒤로가기 → 다른 타이틀 재생 후에도 정상 동작한다
- [ ] 전환 후 플레이바 버튼이 중복 생성되지 않는다 (1개만)

### D. 컨트롤 바
- [ ] 마우스를 움직여 컨트롤 바가 사라졌다 다시 나타나도 버튼이 있다
- [ ] 버튼 hover 시 다른 Netflix 버튼과 같은 강조 효과가 난다

### E. 설정 변경 (설정 UI에서)
- [ ] 번역 텍스트 크기 슬라이더 → 즉시 반영
- [ ] 번역 텍스트 색상 → 즉시 반영, 플레이바 버튼 아이콘 색도 변경
- [ ] 원본 텍스트 색상 → 즉시 반영
- [ ] 원본/번역 투명도 → 즉시 반영
- [ ] "Enable Dual Subtitles" OFF → 번역 자막 숨김, 원본 자막이 원래 위치/흰색으로 복귀
- [ ] "Enable Dual Subtitles" ON → 복원
- [ ] "Stacked Subtitles" OFF → 좌우 배치로 전환 / ON → 스택으로 복귀
- [ ] Restore Defaults → 모든 값이 기본값으로
- [ ] 새로고침 후 설정이 유지된다 (특히 Stacked OFF 상태 — 기존 버그 `background.js:129`)

### F. 창 크기
- [ ] 브라우저 창 리사이즈 시 번역 자막 위치·크기가 원본을 따라간다
- [ ] 전체화면 진입/해제 후 정상

### G. Edge (가능한 경우)
- [ ] Edge에서 원본 자막이 번역되지 않는다
- [ ] Edge 번역기로 번역 자막이 표시된다

## 픽스처 페이지로 빠른 확인
```
npm run build:dev            # localhost 매치가 추가된 dist/
npm run fixture              # http://localhost:8787/
```
`dist/`를 언팩 로드한 뒤 픽스처 페이지에서 Load video → Subtitle 버튼으로 A/B/C/D 항목의 DOM 동작을 Netflix 없이 확인할 수 있다. 번역기 드롭다운으로 Chrome/Edge 번역기 동작을 흉내 낸다.

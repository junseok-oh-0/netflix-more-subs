# 수동 스모크 체크리스트

각 Phase 완료 시 실제 Netflix에서 아래를 확인한다. 자동 테스트(픽스처)는 레이아웃·번역기·DRM을 재현하지 못하므로 이 목록이 최종 게이트다.

표기: `[y]` 성공 · `[n]` 실패 · `[?]` 코멘트 필요 · `[ ]` 미실행. `n`/`?`는 항목 뒤에 ` -> 코멘트`를 붙인다.
실행 기록은 각 Phase 문서에 남기고, 발견된 결함은 `REFACTORING_PLAN.md` §5 표에 등록한다.

마지막 실행: 2026-09-24 (Original Text Size 설정 + 폰트 배율 폭주 버그 수정, E2E 브리지로 검증) — 원본 크기 배율이 미러(번역)에 전혀 영향 안 줌을 실측 확인(원본 54→81px 1.5배, 미러 54px 그대로), 진짜 창 리사이즈 2회(1920→1400→1920) 후에도 비율 정확히 유지(폭주 없음). E-11·G·B-4 미실행. **B-4(긴 자막) 시도 중 별개의 미검증 이슈 발견** — 아래 "발견된 이슈" 참고. 이전 실행: 2026-09-24(NLLB 통합, `docs/NLLB_TRANSLATION.md`), 2026-09-16 (`REFACTORING_PHASE_7.md`).

### 발견된 이슈 (오늘 수정 범위 밖, 별도 확인 필요)
- **B-4 긴 자막**: 4줄 분량의 긴 대사에서 스택 모드 미러가 세로로 줄바꿈되며 플레이어 영역 아래로 넘쳤다(`bottom` 84px 초과). `shrinkContainerToFit`은 가로 폭(`offsetWidth`) 기준으로만 축소를 판단해 세로 줄바꿈은 잡지 못하는 것으로 보인다. 이 항목은 이번 세션의 모든 스모크 실행에서 매번 `[ ]`(미실행)이었던, 애초에 한 번도 검증된 적 없는 부분이라 오늘 작업(Original Text Size, 버그 수정)과 무관한 기존 gap으로 판단. 별도 작업으로 조사 필요

## 준비
1. `npm run build` (E 항목까지 자동화하려면 `npm run build:dev` — 팝업 없이 설정을 바꾸는 E2E 브리지 포함, `docs/SMOKE_AUTOMATION.md` 참고) → `chrome://extensions` → "압축해제된 확장 프로그램 로드" → `dist/` 선택 (이미 로드돼 있으면 "새로고침")
   **그다음 Netflix 탭도 새로고침한다.** 열려 있던 탭에는 이전 content script가 남아 있어 옛 코드의 에러(`Failed to fetch`, 설정 미반영)가 보인다.
   dev 빌드를 썼다면 스모크가 끝난 뒤 **반드시 `npm run build`로 되돌리고 다시 새로고침**한다.
2. 외국어 자막이 있는 아무 타이틀 재생 (예: 노르웨이어 자막)
3. 우클릭 → "한국어로 번역" (브라우저 번역기 활성화) — I 항목(로컬 번역 모드)에서는 필요 없음

## 체크 항목

### A. 재생 시작
- [y] 원본 자막 아래(스택 모드)에 번역 자막이 표시된다
- [y] 원본 자막은 번역되지 않고 원문 그대로다
- [y] 콘솔에 확장 관련 uncaught 에러가 없다
- [y] 브라우즈 페이지에서 미리보기 영상이 재생돼도 콘솔 에러가 없다 (SM-6)
- [y] 플레이어 위에서 우클릭 → 브라우저 컨텍스트 메뉴(번역 항목)가 열린다

### B. 자막 흐름
- [y] 자막이 바뀔 때 번역 자막도 따라 바뀐다
- [y] 자막이 사라질 때 번역 자막도 사라진다 (잔상 없음)
- [y] 두 줄 자막이 정상 표시된다 — 번역이 원본 아랫줄과 겹치지 않고 아래에 붙는다 (SM-2)
- [ ] 긴 자막이 화면 밖으로 나가지 않고 폰트가 줄어든다 (원본 텍스트 크기를 키운 상태에서도 — 축소는 그 크기를 기준으로 더 줄어든다)

### C. 비디오 전환
- [y] 다음 에피소드 자동재생 후에도 번역 자막이 계속 표시된다 (SM-1)
- [y] 뒤로가기 → 다른 타이틀 재생 후에도 정상 동작한다

### E. 설정 변경 (확장 아이콘 팝업에서)
- [y] 팝업을 열면 현재 저장된 값이 컨트롤에 표시된다
- [y] 번역 텍스트 크기 슬라이더 → 즉시 반영
- [y] 원본 텍스트 크기 슬라이더 → 즉시 반영, 번역 자막 크기는 원본 배율과 무관하게 유지된다 (2026-09-24: 원본 1.5배 시 54→81px, 번역 자막은 54px 그대로 — 실제 창 리사이즈 2회 후에도 비율 1.5 정확히 유지, 폭주 없음 확인)
- [y] 번역 텍스트 색상 → 즉시 반영
- [y] 원본 텍스트 색상 → 즉시 반영
- [y] 원본/번역 투명도 → 즉시 반영
- [y] "Enable Dual Subtitles" OFF → 번역 자막 숨김, 원본 자막이 원래 위치/흰색으로 복귀
- [y] "Enable Dual Subtitles" ON → 복원
- [y] "Stacked Subtitles" OFF → 좌우 배치로 전환 / ON → 스택으로 복귀
- [ ] Reset Settings → 크기(번역·원본 둘 다)·색상·투명도가 기본값으로 (on/off·Stacked는 유지) — 원본 크기 포함 재확인 필요
- [y] 새로고침 후 설정이 유지된다
- [ ] Stacked OFF 상태로 **브라우저를 완전히 종료 후 재시작** → 여전히 OFF (SW 재시작 리셋 버그 해소 확인)

### F. 창 크기
- [y] 브라우저 창 리사이즈 시 번역 자막 위치·크기가 원본을 따라간다
- [y] 전체화면 진입/해제 후 정상

### H. 설정 UI 일원화 (Phase 2)
- [y] 플레이바에 확장이 추가한 버튼이 없다
- [y] 페이지 안에 설정 패널이 나타나지 않는다
- [y] `chrome://extensions`에서 확장 오류 없음 (manifest `web_accessible_resources` 제거 영향)

### G. Edge (가능한 경우)
- [ ] Edge에서 원본 자막이 번역되지 않는다
- [ ] Edge 번역기로 번역 자막이 표시된다

### I. 로컬 번역 모드 (server/ 실행 중일 때만)
- [y] 팝업/브리지에서 Translator를 Local Server로 전환하면 미러 `translate`가 `no`로 바뀐다
- [y] 원문이 먼저 보이고 곧 실제 서버 응답(번역문)으로 교체된다 (2026-09-24: 영어→한국어, ~300ms, 10회 이상 전환 성공)
- [y] 브라우저 번역기가 켜져 있어도 이중 번역되지 않는다 (`translate="no"`가 유지되므로)
- [y] `Translator`를 Browser로 되돌리면 다음 자막부터 다시 `translate="yes"`로 브라우저 번역기 경로 사용
- [ ] 서버가 꺼져 있을 때 원문이 계속 표시되고 확장이 죽지 않는다 (실패 시 원문 유지 로직은 유닛 테스트로만 확인됨, 실서버 다운 상황은 미검증)

## 픽스처 페이지로 빠른 확인
```
npm run build:dev            # localhost 매치가 추가된 dist/
npm run fixture              # http://localhost:8787/
```
`dist/`를 언팩 로드한 뒤 픽스처 페이지에서 Load video → Subtitle 버튼으로 A/B/C/D 항목의 DOM 동작을 Netflix 없이 확인할 수 있다. 번역기 드롭다운으로 Chrome/Edge 번역기 동작을 흉내 낸다.

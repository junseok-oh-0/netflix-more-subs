# 수동 스모크 체크리스트

각 Phase 완료 시 실제 Netflix에서 아래를 확인한다. 자동 테스트(픽스처)는 레이아웃·번역기·DRM을 재현하지 못하므로 이 목록이 최종 게이트다.

표기: `[y]` 성공 · `[n]` 실패 · `[?]` 코멘트 필요 · `[ ]` 미실행. `n`/`?`는 항목 뒤에 ` -> 코멘트`를 붙인다.
실행 기록은 각 Phase 문서에 남기고, 발견된 결함은 `REFACTORING_PLAN.md` §5 표에 등록한다.

마지막 실행: 2026-09-16 (Phase 3 `9c17a66`) — SM-1·SM-2 해소 확인, SM-6 발견 (결과는 `REFACTORING_PHASE_3.md`). 아래는 Phase 4+5용으로 초기화된 목록.

## 준비
1. `npm run build` → `chrome://extensions` → "압축해제된 확장 프로그램 로드" → `dist/` 선택 (이미 로드돼 있으면 "새로고침")
   **그다음 Netflix 탭도 새로고침한다.** 열려 있던 탭에는 이전 content script가 남아 있어 옛 코드의 에러(`Failed to fetch`, 설정 미반영)가 보인다.
2. 외국어 자막이 있는 아무 타이틀 재생 (예: 노르웨이어 자막)
3. 우클릭 → "한국어로 번역" (브라우저 번역기 활성화)

## 체크 항목

### A. 재생 시작
- [y] 원본 자막 아래(스택 모드)에 번역 자막이 표시된다
- [y] 원본 자막은 번역되지 않고 원문 그대로다
- [y] 콘솔에 확장 관련 uncaught 에러가 없다
- [y] 브라우즈 페이지에서 미리보기 영상이 재생돼도 콘솔 에러가 없다 (SM-6)
- [y] 플레이어 위에서 우클릭 → 브라우저 컨텍스트 메뉴(번역 항목)가 열린다

### B. 자막 흐름
- [y] 자막이 바뀔 때 번역 자막도 따라 바뀐다
- [y] 자막이 사라질 때 번역 자막도 사라진다 (잔상 없음)
- [y] 두 줄 자막이 정상 표시된다 — 번역이 원본 아랫줄과 겹치지 않고 아래에 붙는다 (SM-2)
- [ ] 긴 자막이 화면 밖으로 나가지 않고 폰트가 줄어든다

### C. 비디오 전환
- [y] 다음 에피소드 자동재생 후에도 번역 자막이 계속 표시된다 (SM-1)
- [y] 뒤로가기 → 다른 타이틀 재생 후에도 정상 동작한다

### E. 설정 변경 (확장 아이콘 팝업에서)
- [y] 팝업을 열면 현재 저장된 값이 컨트롤에 표시된다
- [y] 번역 텍스트 크기 슬라이더 → 즉시 반영
- [y] 번역 텍스트 색상 → 즉시 반영
- [y] 원본 텍스트 색상 → 즉시 반영
- [y] 원본/번역 투명도 → 즉시 반영
- [y] "Enable Dual Subtitles" OFF → 번역 자막 숨김, 원본 자막이 원래 위치/흰색으로 복귀
- [y] "Enable Dual Subtitles" ON → 복원
- [y] "Stacked Subtitles" OFF → 좌우 배치로 전환 / ON → 스택으로 복귀
- [y] Reset Settings → 크기·색상·투명도가 기본값으로 (on/off·Stacked는 유지)
- [y] 새로고침 후 설정이 유지된다
- [ ] Stacked OFF 상태로 **브라우저를 완전히 종료 후 재시작** → 여전히 OFF (SW 재시작 리셋 버그 해소 확인)

### F. 창 크기
- [y] 브라우저 창 리사이즈 시 번역 자막 위치·크기가 원본을 따라간다
- [y] 전체화면 진입/해제 후 정상

### H. 설정 UI 일원화 (Phase 2)
- [y] 플레이바에 확장이 추가한 버튼이 없다
- [y] 페이지 안에 설정 패널이 나타나지 않는다
- [y] `chrome://extensions`에서 확장 오류 없음 (manifest `web_accessible_resources` 제거 영향)

### G. Edge (가능한 경우)
- [ ] Edge에서 원본 자막이 번역되지 않는다
- [ ] Edge 번역기로 번역 자막이 표시된다

## 픽스처 페이지로 빠른 확인
```
npm run build:dev            # localhost 매치가 추가된 dist/
npm run fixture              # http://localhost:8787/
```
`dist/`를 언팩 로드한 뒤 픽스처 페이지에서 Load video → Subtitle 버튼으로 A/B/C/D 항목의 DOM 동작을 Netflix 없이 확인할 수 있다. 번역기 드롭다운으로 Chrome/Edge 번역기 동작을 흉내 낸다.
